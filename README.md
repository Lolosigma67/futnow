# futnow2
FutNow es una plataforma web pensada para conectar a futbolistas aficionados, permitiéndoles crear un perfil deportivo con su edad, posición, nivel de juego y zona geográfica para buscar compañeros, armar equipos u organizar partidos de forma rápida a través de contacto directo por WhatsApp y visualización de perfiles dinámicos desde una base de datos
